## Что посмотреть

**[MemoryGuard](https://github.com/VladimirKozulin/KMS).** Дедупликация памяти ядра Linux (KSM) для Docker-контейнеров. На стенде из 30 контейнеров при 2 300 RPS агент экономил 35% памяти в простое и только 8% под нагрузкой. В README разобрано, почему так. Адаптивный тюнер ksmd сканирует на 22% меньше и при этом экономит на 23% больше. Java 21, GraalVM native, C, ptrace.

**[Two Morrows](https://github.com/VladimirKozulin/twomorrows).** Открытая библиотека книг, музыки и аудиокниг. Сервер хранит записи, а не файлы: узнаёт одну песню в разных форматах по акустическому отпечатку и держит одну копию. Lossless-мастер хранится как Opus плюс остаток, это на 12–14% меньше пары FLAC + Opus. Quarkus, PostgreSQL, MinIO, Keycloak, Flutter.

**[Grafana #135483](https://github.com/grafana/grafana/pull/135483).** Разметка редакторов источников данных для перевода. Мой первый PR в большой открытый проект.

## По работе (код закрыт)

- Платформа паримьютюэльных ставок и прогнозов. CQRS и Event Sourcing на Axon с PostgreSQL в роли event store, математика пулов, котировки через WebSocket и Protobuf, клиент на Flutter.
- CRM для юридической фирмы. Модульный монолит на Spring, тяжёлые отчёты, уведомления в почту и Telegram через брокер, разворачивается одной командой.
- Видеоаналитика. Приём видеопотоков, Netty на тысячи открытых соединений, Circuit Breaker перед внешними сервисами распознавания.
- Маркетплейс серверного железа. Заодно собирал и настраивал сами серверы, включая InfiniBand.

Стек: Java, Spring Boot, Quarkus, PostgreSQL, Redis, Kafka, Docker, Linux, Flutter.
